# 编排只用单链，并行只来自异步任务节点

编排的主链和子流程都是严格单入单出的链，不支持 DAG 分叉和汇合；需要并行时，由异步任务节点触发一个子流程，主链不等待它。之所以不采用更通用的 DAG + 控制节点（条件、foreach、join、try/catch），是因为测试编排要尽可能简单明了，一条链的执行顺序和失败影响一眼就能看出来；而两种并行机制同时存在，会导致失败传播和运行结束条件出现两套规则。

## Considered Options

- **通用结构化 DAG**（调研报告的方案）：表达力最强，但语义规则多，画布也更难读。
- **DAG + 异步子流程并存**：同一件事有两种写法，被否决。

## Consequences

- 主链拿不到子流程的输出（没有 join）。将来需要时，可以在 IR 的 `schemaVersion` 下兼容地增加 join 节点。
- 失败后的清理依赖 `always` 节点，这是单链之外唯一新增的语义。
