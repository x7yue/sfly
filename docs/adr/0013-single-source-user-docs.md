# 用户文档只有一份 Markdown，同时供前端渲染和 AI 编程助手用 curl 读取

面向用户的开发文档（快速开始、安装 Agent、初始化项目、开发节点、本地调试、联调、发布、AI 编程助手快速开始）只维护 `docs/guide/` 下的一组 Markdown。构建时打进控制面：前端「开发文档」页面渲染它们，控制面同时以原文提供 `/docs/<页>.md` 和索引 `/llms.txt`，返回时填入控制面地址和版本号，复制出来的命令可以直接运行。SDK 参考同时作为节点开发 skill 的 `reference.md` 打进 SDK，让 AI 编程助手在项目里不联网也能读到。这样文档跟着控制面版本走，人和 AI 编程助手读到的是同一份内容。

## Considered Options

- **前端页面和给 AI 的文档分开写**：两份内容迟早不一致。
- **独立的文档站**：多一个要部署的服务，内网用户也不一定能访问，版本还会和控制面脱节。
