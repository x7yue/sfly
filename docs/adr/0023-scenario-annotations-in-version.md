# 显示名称、备注和注释框属于场景版本，注释框只记成员、不存坐标

场景作者给节点起的显示名称、写的备注，以及框住一组节点和子流程的注释框，都保存在场景文档里，属于场景版本的内容：只改一句备注，保存后也是一个新版本；运行显示的是它绑定的那个版本里的名称和说明。场景的名称、说明和运行通知的设置仍然不属于版本。注释框只记录成员（节点 ID 和子流程入口的节点 ID），不保存坐标和大小，框的范围由成员算出，算法和子流程区域相同。所以注释框不能自由摆放，也不能调整大小；非成员节点落在框里时，以成员列表为准。这样命令行和 AI 编程助手不写坐标也能加注释框，节点移动时框跟着变。三者都只用于显示，不影响执行（SEMANTICS）。

## Considered Options

- **说明不属于版本，像场景名称一样立即生效**：要按节点 ID 另外存一份，节点删除、回看旧版本时都对不上；运行也没法显示当时的说明。
- **注释框保存坐标和大小，可以自由摆放**：命令行编辑场景时要自己算坐标；节点挪动后框和节点脱节；「哪些节点属于这个框」只能按几何位置推断，挪动一下节点就改变了归属。

## Consequences

- 只改说明也会多出版本。这和布局一样：拖动节点本来就会产生新版本。
- 注释框引用了不存在的节点或子流程时，保存只给警告，不阻断触发；画布跳过这些成员画框，不会在打开或保存时偷偷删掉它们。
