# 平台不建模用户和测试环境

平台不做登录和权限，也没有"测试环境"这个概念：任务在哪个 Agent 上执行，就在哪个环境执行；编排级别指定默认 Agent，单个节点可以另选 Agent；要在另一个环境执行同一套编排，就复制一份编排并重命名。这样做的原因是：平台只部署在内网，每个人都有自己独立的测试环境，彼此不会争抢资源，引入用户、环境、资源锁和 Agent 自动选择，会增加大量概念，却换不来实际收益。

## Consequences

- 只用浏览器里填写的昵称标记版本作者、运行触发人和在线编辑者，这个昵称不做鉴权。
- 防止并发修改依靠编排版本的乐观锁和在线编辑者提示，而不是权限控制。
- 编排里直接写的是 Agent 名称；复制编排后需要手动改成另一个 Agent。
