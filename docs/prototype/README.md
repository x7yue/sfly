# 前端正式化 · 定稿原型 v2

`frontend-v2.html` 是单文件、可点击的交互原型，直接用浏览器打开即可，不需要构建或网络。它是「前端正式化」规格中信息架构、布局与交互的依据；视觉细节（具体组件外观）以落地时的组件库实现为准，配色与规则以设计 token 为准。

原型里的数据、图表曲线和日志都是演示数据；编排画布只画了「日终数据处理」一个场景。

入口：

- `#/dashboard` 控制台、`#/scenarios` 场景编排（卡片 / 表格、运行抽屉）、`#/runs` 运行记录、`#/agents`、`#/packages`
- `#/editor/s1` 全屏编排画布（编辑 / 运行状态）
- `#/monitor/0194692f`（小型运行）、`#/monitor/b7e2a91c`（30 节点、42 张图表）、`#/monitor/259c7e70`（失败的运行）
