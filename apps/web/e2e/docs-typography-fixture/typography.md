## `@node` 与 `ctx.log`

节点函数写在节点包里，由测试机上的 Agent 按场景里的编排顺序执行；函数的参数来自入口参数和上游节点的输出，返回值成为下游节点可以引用的输出。这一段故意写得很长，用来检查正文每行的宽度、行高和最后一行的折法，其中夹着行内代码 `ctx.progress(current, total)`。
